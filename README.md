# replanto
A small mod aimed at simplifying the replanting process.

## How does it work?
Just simply hold the item in your main/offhand that is being replanted (carrots, wheat seeds, cocoa beans, etc)
- Works with fortune hoe as long as its in your main hand
- Does NOT replant sugarcane or cactus as those aren't usually fully harvested so was not implemented.
